LICENÇA DA FONTE EMBUTIDA
=========================

Liberation Mono — a única fonte do projeto
------------------------------------------
Arquivos de origem: LiberationMono-Regular.ttf, LiberationMono-Bold.ttf e
LiberationMono-Italic.ttf, do projeto Liberation Fonts
(https://github.com/liberationfonts), versão instalada em
/usr/share/fonts/truetype/liberation/.

O arquivo fontes.css embute as três faces como woff2 recortado (subset), só
com os intervalos que o site usa:

  U+0020-007E, U+00A0-00FF, U+0100-017F, U+2010-2027, U+2039-203A,
  U+20AC, U+2116, U+25B2, U+25BA, U+25BC, U+25C4, U+25CF, U+25CB, U+2660

O U+2660 (♠) é a marca do site e U+25B2/U+25BC/U+25C4/U+25BA são as
setas da interface (▲ ▼ ◄ ►). Nenhum glifo foi redesenhado: o desenho é o
mesmo da fonte original, só sem os caracteres que o site não usa. A marca-d'água
e o favicon usam o contorno do ♠ num path SVG, com as coordenadas originais
do contorno. A família embutida se chama "ASCII Mono", porque a
OFL pede que versões modificadas troquem o nome.

O U+00A0 (espaço não separável) é um glifo simples e vazio, com o mesmo
avanço da fonte original. No Liberation Mono ele é um glifo composto que
aponta para o `space`; mantido assim, o sanitizador de fontes do Firefox
(OTS) registra "empty gid N used as component in glyph M" no console. O aviso
não rejeita a fonte, mas é ruído; por isso o recorte troca o composto por um
glifo simples vazio, sem mexer no desenho nem no avanço. O avanço não muda
porque ele vive na tabela `hmtx`, não no `glyf`: trocar o contorno composto
por um vazio simples não altera a largura.

Como conferir o recorte, com fonttools e brotli instalados (python3):

    from fontTools.ttLib import TTFont
    f = TTFont('fontes.woff2')
    ordem = f.getGlyphOrder()
    vazio = {n for n in ordem if f['glyf'][n].compile(f['glyf']) == b''}
    for n in ordem:
        g = f['glyf'][n]
        if g.isComposite():
            for c in g.components:
                if c.glyphName in vazio:
                    print('aviso OTS:', ordem.index(n), n, c.glyphName)

Se aparecer alguma linha, troque o glifo composto por um vazio simples:

    from fontTools.ttLib import TTFont
    from fontTools.ttLib.tables._g_l_y_f import Glyph

    f = TTFont('entrada.woff2', recalcBBoxes=False, recalcTimestamp=False)
    nome = f['cmap'].getBestCmap()[0x00A0]
    f['glyf'][nome] = Glyph()
    f['glyf'][nome].numberOfContours = 0
    f.flavor = 'woff2'
    f.save('saida.woff2')

Não há script de build para a fonte: gere o woff2 com pyftsubset
(layout-features vazio) e embuta em base64 no fontes.css. As três faces
precisam ser recortadas de novo e reembutidas também em public/cofre-btc.html,
que mantém cópia própria do base64 para ser standalone; o `npm test` compara
as duas cópias e acusa a divergência.
